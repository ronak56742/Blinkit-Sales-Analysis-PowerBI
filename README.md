# Blinkit Sales Analysis Dashboard 📊

This project presents an interactive Power BI dashboard analyzing Blinkit grocery sales data.

## 🔍 Project Overview
The dashboard provides insights into:
- Total sales and average sales
- Number of items sold
- Average customer ratings
- Sales trends by outlet size, type, and location
- Item type and fat content analysis

## 🛠 Tools Used
- Power BI
- Excel / CSV Dataset
- DAX Measures

## 📈 Key Insights
- Tier 3 outlets generate the highest sales
- Regular fat content items outperform low-fat items
- Fruits, snacks, and household items contribute maximum revenue
- Outlet establishment year impacts sales growth trends
